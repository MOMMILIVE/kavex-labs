The original Kavex landing page and secondary pages remain available. The existing “Commission a Ring” buttons now enter `/bespoke`, a three-step React configurator styled with the site's monochrome laboratory identity and existing logo. The preview includes a procedural, draggable ring, source catalogue references, live NOK quotes, ring sizes and three engraving font previews. The visualization is distinct from final workshop CAD and the individually approved stone.

Run `npm ci`, then `npm run dev`. Open `http://127.0.0.1:4311/` for the original landing page or `/bespoke` for the configurator. `npm run build`, `npm run typecheck` and `npm test` validate the implementation. Generated `public/` files are deliberately excluded from Git and prepared during every build.

Checkout uses `pages/api/checkout.ts`, hosted Stripe Checkout, NOK and the requested `['klarna', 'card']`. It charges the full configured quote, calculated and validated on the server. Custom carats go to the private concierge. The route uses server-held keys, origin validation and Stripe idempotency. Both session and PaymentIntent metadata include the build specification for reconciliation. No existing merchant configuration is changed.

The NOK matrix is for review: 1.0ct gold 25,000; 1.5ct gold 32,000; 2.0ct gold 39,500. Emerald adds 1,200, Radiant 1,500, Pear 900 and Platinum 6,000 NOK. Standard font/engraving and ring-size choices do not change the quote. Treat these as complete consumer totals: approve the margins, applicable VAT and delivery costs before enabling live sales, then set `PRICING_APPROVED=true` with `STRIPE_SECRET_KEY` and the production `APP_URL`. Preview deployments derive their own origin from Vercel's environment. No secret keys are committed.

Create an idempotent signed webhook handler before automated order fulfillment. Handle `checkout.session.completed` and `checkout.session.async_payment_succeeded`, verify `payment_status === 'paid'`, the currency and total, and persist the order once. Handle failed/expired events. A success redirect alone never proves payment. This change provides the requested frontend and Checkout creation route; it does not start manufacturing, send WhatsApp messages, or create an order database.

The existing `/api/analyze` endpoint is preserved through a Pages Router wrapper and continues using its existing environment configuration. No private client chat, quotation or address is included in this integration.
