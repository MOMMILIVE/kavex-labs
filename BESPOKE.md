The Kavex commissioning experience at `/bespoke` is a visual, price-free questionnaire. Customers choose one thing at a time: diamond shape, scale, precious metal, then optional engraving and ring size. Guidance is available for each core decision. A final editable brief asks for name and WhatsApp number and opens a customer-controlled WhatsApp draft. The customer must send the draft; this does not silently save a lead, send a message, charge a deposit, or promise a locked quote. Private concierge remains accessible throughout.

The original Kavex landing page and secondary routes remain available. Its generic retail-price calculator has been replaced with a monochrome private-commission entry. Existing “Commission a Ring” links enter `/bespoke`. The new page uses the existing wordmark, Geist typography and precious-metal photography. `assets/bespoke/atelier-hero.png` is newly generated editorial design inspiration, labeled accordingly; it does not document an actual selected diamond. Distinct SVG cut diagrams replace the procedural WebGL ring. There are no client pricing tiers or checkout calls in the questionnaire.

Run `npm ci`, then `npm run dev`. Open `http://127.0.0.1:4311/bespoke`. `npm run build`, `npm run typecheck` and `npm test` validate the implementation. Generated public assets and original static routes are prepared before dev/build.

The previously requested standard Checkout route remains in `pages/api/checkout.ts` for later integration after personal stone/design approval. It is disconnected from this public flow. It uses server-calculated review tiers, hosted Stripe, NOK, Klarna and card, same-origin checks, strict validation and Stripe idempotency. Live charging requires `PRICING_APPROVED=true`; the example matrix is not an approved sales price. No keys or merchant account settings are committed or changed. Signed payment webhooks and persisted orders are still needed before any automated fulfillment; a redirect does not prove payment.

The existing `/api/analyze` endpoint is preserved. No private client chats, quotations, addresses or contact details are bundled. The WhatsApp destination is the business number already published on the Kavex site.
